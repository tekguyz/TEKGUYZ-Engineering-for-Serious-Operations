## 🚀 Operations (Local Setup)

To spin up the TEKGUYZ environment locally:

1. **Clone the repository**
2. **Install dependencies**:
   ```bash
   npm install
   ```
3. **Configure Environment**:
   Copy `.env.example` to `.env.local` and provide your `GEMINI_API_KEY`.
4. **Launch Dev Server**:
   ```bash
   npm run dev
   ```
   The environment will be available at `http://localhost:3000`.

## 🔒 Security & Privacy

We adhere to a "Server-Side First" security model. All sensitive API keys and intelligence logic are handled via Next.js Route Handlers to prevent client-side exposure.
